📊 **Blinkit Sales \& Delivery Analysis using SQL**



### 🔍 Project Overview



This project focuses on analyzing Blinkit’s sales, customer behavior, product performance, and delivery efficiency using SQL. The goal is to extract meaningful business insights from structured data and support data-driven decision-making.



### 🎯 Objective

* Analyze overall sales performance and revenue trends
* Identify top-performing products and categories
* Understand customer behavior and segmentation
* Evaluate delivery performance and identify delay causes
* 

### 🗂️ Dataset Description



The analysis is based on the following relational tables:



**blinkit\_orders** → Order-level transaction data

**blinkit\_order\_items** → Product-level order details

**blinkit\_products** → Product information (category, price, etc.)

**blinkit\_customers** → Customer details and segmentation

**blinkit\_delivery\_performance** → Delivery time and status data



### 🔗 Data Relationships



* Customers are linked to orders via customer\_id
* Orders are linked to order items via order\_id
* Products are linked to order items via product\_id
* Delivery performance is linked to orders via order\_id



### 🛠️ Tools \& Technologies



* Excel
* SQL (MySQL)
* Relational Database Concepts
* Data Cleaning \& Transformation
* Data Analysis using Joins and Aggregations



### 📈 Key Analysis Performed



##### 🟢 Sales Analysis



* Total revenue generated
* Order trends over time
* Average order value



##### 🟢 Product Analysis



* Top-selling products
* Revenue by category
* Product demand patterns



##### 🟢 Customer Analysis



* Top customers by spending
* Customer segmentation insights
* Repeat customer behavior



##### 🟢 Delivery Analysis



* On-time vs delayed deliveries
* Delivery time vs distance
* Delay reasons analysis



### 💡 Key Insights



* Traffic is the primary cause of delivery delays, significantly impacting delivery performance.
* A small group of products contributes to a large portion of total sales, indicating demand concentration.
* Certain product categories generate higher revenue, making them key business drivers.
* Premium customers tend to contribute more revenue compared to other segments.
* Most deliveries are completed on time, but delays highlight opportunities for operational improvement.



### 🧠 Conclusion



The analysis highlights important business trends in sales, customer behavior, and delivery operations. These insights can help optimize inventory, improve delivery efficiency, and enhance customer experience.
